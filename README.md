# 科研报告 Word 排版工作流

整理中文材料科研报告的 Word 排版。项目包括一套可供 Codex 执行的完整工作流、可编辑的 Word 模板，以及在本地运行的 Python 命令行工具。支持 Windows、macOS 和 Linux 上的 Python 3.10 或更高版本。

## 一句话让 AI 排版

复制下面这句话，把引号里的路径换成你的 Word 文件路径。如果已经上传文件，就把引号里的内容换成“我上传的 Word 附件”。

```text
请按 https://github.com/jiazuolong/format-research-word.git 的完整工作流和样式模板，帮我把“新文件的完整路径.docx”排好版，检查后另存为新的 Word 文件发给我。
```

收到这句话时，AI 应读取完整工作流，默认使用仓库里的 Word 模板。若另附指定模板，则使用指定模板。使用仓库模板时，按段落用途实际应用「一级标题xx」「二级标题xx」「三级标题xx」「正文xx」「题注xx」。完成科学文本、表格和引文排版后，按默认规范生成或更新三级自动目录并核对页码，重新打开成稿，在 Word“样式”窗格中核对各级标题，再交付可编辑的 `.docx`。[完整工作流](SKILL.md) · [Word 样式模板](assets/report-styles.docx)

## 本地运行

在终端中克隆项目并安装。建议使用 Python 虚拟环境。

```sh
git clone https://github.com/jiazuolong/format-research-word.git
cd format-research-word
python -m pip install .
format-research-word audit "报告.docx" --json "排版检查.json"
format-research-word format "报告.docx" "报告_排版版.docx"
```

已完成其他排版的报告，可以只应用表格自适应和上标这两项规则：

```sh
format-research-word format "报告.docx" "报告_表格与上标版.docx" --layout-only
```

希望同步重排静态方括号引文时，先检查 JSON 中的编号映射、未引用条目和待判定标记，再将下列命令作为排版步骤。输出路径应使用新文件名。

```sh
format-research-word format "报告.docx" "报告_引文排版版.docx" --renumber-citations
```

`python -m format_research_word` 与已安装的命令等效。仅需盘点文献与数字时，也可直接从仓库运行 `python scripts/audit_report.py "报告.docx"`，这条命令只使用 Python 标准库。文档处理在本机完成。

## 排版规则

| 项目 | 示例与处理 |
| --- | --- |
| 化学式 | 识别常见元素组合和组分表达式。元素与计量数使用 Times New Roman，计量数和化学式中的组分系数使用 Word 原生下标。 |
| 表格布局 | 每张表先按内容调整列宽，再适配窗口。整表首选宽度为100%，允许列宽随内容变化；嵌套表适配父单元格。 |
| 上标 | 单位幂次、离子电荷、上标引文和注号均用 Word 原生上标、Times New Roman 字体。例如 cm⁻¹ 的指数在 Word 中为普通字符“−1”加上标。Word 公式的指数保留原生公式结构。 |
| 变量 | 组分变量 x 用正体，保留乘号 ×。 |
| 数值 | 小数部分达到五位时保留三位有效数字。−4.497105916 → −4.50，0.01870 → 0.0187。四位小数 10.9415 保留原值。 |
| 空格 | “在 300K 下，用 DFT 计算”变为“在300 K下，用DFT计算”。数值和物理单位间保留一个空格，百分号同样处理。 |
| 参考文献 | 若第一处是 [3,1]，两篇文献依次获得新号 1、2。后续引用复用新号；文末整条移动，未引用文献按原相对顺序追加。 |
| 模板与编号 | 完整工作流依目标模板处理正文、大纲、图表题注、公式号、附录及交叉引用，最后在 Word 中重新分页并刷新目录。 |

### 命令行的处理范围

`format` 修改主文档内的常规文本段落、图表题注和表格文字，可跨相邻文本片段识别化学式；处理原生数学公式中单个数学文本片段里的长小数、组分变量 x 和微分 dx。图件和嵌入对象随 DOCX 保存。它沿用输入文档的页面和段落样式。对于 Word 表格，工具清除固定单元格宽度偏好，并写入自动布局和100%首选表宽，实际列宽在 Word 排版时计算。表格和上标规则同时覆盖页眉、页脚、脚注、尾注内的可编辑内容。章节合并、指定模板套用、复杂公式、图片内文字、脚注和最终目录分页，按 [完整工作流](SKILL.md) 在 Word 或文档代理中处理。

`--renumber-citations` 适用于正文使用方括号、文后每条记录独占一段且有可编辑编号的单一书目。组合引用和区间会展开，按新号排序。整数坐标与引文可能写成相同的方括号形式，需要结合上下文判断。含 Zotero、EndNote 等动态引用、脚注引用、修订记录或歧义编号时，请使用原文献管理机制与工作流。检查报告中的段落号按文档读取顺序计算，包含表格中的段落。

### 生成三级自动目录

使用首页的一句话排版时，AI 在正文和章节编号定稿后生成可点击的 Word 自动目录。已有章节目录就在原位置更新，新建目录放在封面等前置内容之后、首个正文标题之前。正文的「一级标题xx」「二级标题xx」「三级标题xx」分别对应 TOC 1、TOC 2、TOC 3。「目录」二字居中，使用黑体三号（16 磅）。三个级别的目录条目统一使用中文宋体、西文 Times New Roman，小四（12 磅）、常规字形。条目均左对齐，左缩进 2 字符，右缩进 0，无特殊缩进。段前 0 行，段后 8 磅，多倍行距 1.16。定义文档网格时自动调整右缩进并对齐网格。页码右对齐，带点状引导线。另附指定模板时以其目录样式为准。

在装有桌面版 Microsoft Word 的 Windows 电脑上，也可在仓库目录运行以下命令。输入应为已经套用标题样式的成稿，支持上述三个项目样式及 Word 内置标题 1 至 3。

```sh
python -m pip install ".[word]"
format-research-word toc "已排版报告.docx" "报告_含目录.docx"
```

此命令按项目默认规范生成目录、用 Word 重新分页、更新页码，保存后重新打开核对。正文中的标题或分页变化后，可在 Word 中选择“更新整个目录”。若使用另指定的目录格式，依完整工作流在 Word 中套用该模板。

## 在 Codex 中使用

将整个仓库作为名为 `format-research-word` 的技能目录放入当前环境的技能目录，例如 `$CODEX_HOME/skills/format-research-word`。保留其中的 `assets`、`scripts` 和 `src`。在能识别该技能的会话中上传报告，输入：

> 使用 $format-research-word 按标准工作流整理附件，核对自适应表格、化学式上下标、数值、单位、引文和目录，另存为新版。

续接两份报告时，说明底稿、来源、起始标题和插入位置。另附格式模板时，以指定模板为准。
